# screenpastel

Create beautiful screenshots with backgrounds, borders, shadows, 3D transforms, and window frames.

## Quick Start

```bash
bun install          # install dependencies
bun run dev          # dev server → http://localhost:3000
bun run build        # production build
bun run start        # start production server
bun run lint         # biome lint check
bun run format       # biome format --write
```

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4, `tw-animate-css`
- **UI:** shadcn/ui (new-york style, neutral base)
- **Package manager:** Bun
- **Linting/formatting:** Biome
- **Icons:** lucide-react
- **Image export:** html-to-image

## Project Structure

```
app/               — Next.js pages + layout (globals.css has theme tokens)
components/
  ui/              — shadcn/ui primitives (excluded from lint)
  *.tsx            — feature components
hooks/             — custom React hooks (useSavedThemes, etc.)
lib/               — utilities, types, data, gradient utils, image exporter
public/            — static assets
```

## Conventions

- **Path alias:** `@/` maps to `./` (project root)
- **Class merge:** use `cn()` from `lib/utils` (clsx + tailwind-merge)
- **Theming:** CSS custom properties in `app/globals.css` → Tailwind v4 `@theme inline`
- **Dark mode:** class-based via `next-themes`, `.dark` class on `<html>`
- **State management:** `useHistory()` from `lib/useHistory` — provides `state`, `setState`, `commit`, `undo`, `redo`
- **Component pattern:** `"use client"` for interactive components; server components for static
- **components/ui/:** excluded from Biome lint (auto-generated by shadcn)
